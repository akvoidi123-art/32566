# LikeHearts (клиентский мод, Fabric 26.1.2)

Ставит сердечко (красное, жёлтое или фиолетовое) над ником игрока и слева от
ника в табе. Видите его только вы — на сервере ничего не меняется и ничего
ставить не нужно.

## Команды

```
/like <ник> <0-3>    1 — красное, 2 — жёлтое, 3 — фиолетовое, 0 — убрать
/like list           показать, кому какие сердечки выданы
```

Ник подсказывается по Tab из игроков онлайн. Данные хранятся в
`config/likehearts.json` и остаются после перезапуска игры.

Ник ищется в отображаемом имени по словам, поэтому работает и с префиксами
(`[VIP] Notch`), и в таблице игроков, и над головой.

## Свои картинки

Сердечки — это обычные PNG внутри мода:
`assets/likehearts/textures/font/heart_1.png` (красное), `heart_2.png`
(жёлтое), `heart_3.png` (фиолетовое). Заменить их можно ресурспаком с теми же
путями, без пересборки мода. Размер любой квадратный (сейчас 16×16),
отрисовывается 10 пикселей над ником и 8 в табе.

## Как устроено

- Над ником: после обычной отрисовки неймплейта мод добавляет ещё одну строку
  с символом сердечка из собственного шрифта (`font/hearts.json`) — она
  поворачивается к камере и ведёт себя так же, как ник. Из-за этого у сердечка
  есть тёмная подложка, как у обычного ника.
- В табе: к имени слева добавляется символ из шрифта `font/tab.json`.

## Сборка

```bash
./gradlew build
```
Готовый jar — `build/libs/likehearts-1.0.0.jar`. Либо через GitHub Actions
(`.github/workflows/build.yml`, jar появится в Artifacts).

Установка: jar + **Fabric API** для 26.1.2 в папку `mods` клиента.
